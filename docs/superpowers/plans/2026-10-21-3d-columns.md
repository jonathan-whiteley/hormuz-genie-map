# 3D Vessel Columns and Playback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn chokepoints and ports into 3D columns whose height is the daily vessel count, animate them over 2026 with a play button, and play Genie time-series answers on the map.

**Architecture:**
- **Pure modules first:**
  - column scale (`map/columns.ts`)
  - playback stepping (`map/playback.ts`)
  - time-series model (`genie/timeSeries.ts`)

  These are unit-tested in vitest's node environment.
- **Layers:** deck.gl `ColumnLayer` replaces the chokepoint and port scatterplots in `map/baseLayers.ts`, and adds answer columns in `map/answerLayer.ts`.
- **Playback hook:** one hook (`map/usePlayback.ts`) drives the shared selected date, both for "play the year" (one day per tick) and "play this answer" (one answer date per tick). The base map and the answer therefore always show the same date.
- **Camera:** pitches to 45 degrees.

**Tech Stack:** AppKit 0.76.1 (React 19, TypeScript 5.9), MapLibre GL 6.13 + deck.gl 9.4 (`ColumnLayer` from `@deck.gl/layers`), vitest 4 (node environment).

**Spec:** `docs/superpowers/specs/2026-10-21-3d-columns-design.md` (read it with this plan). It builds on `docs/superpowers/specs/2026-10-21-elegant-map-design.md`.

## Review Focus

1. **A Hormuz-closed day (value 0 or null) in mid-playback.** The column must still show as a short Lava stub at its place, never vanish or throw. Test: Task 1 "a zero or missing count still draws the minimum stub".
2. **Zooming in on an answer.** Columns must not overflow the screen at zoom 7 or shrink to nothing at zoom 2. Height and radius scale with zoom. Test: Task 1 "elevation scale and radius keep about the same screen size across zoom".
3. **A time-series answer with monthly strings ("2026-02"), unsorted rows, a missing month for one place, and several places.** It must play in date order; a place with no value yet shows nothing for that frame. Test: Task 3 "monthly strings, unsorted rows, gaps and several places".
4. **Pressing play at the end of the timeline, or dragging the slider during playback.** Play at the end restarts from the start; a drag pauses. Test: Task 2 "play at the end restarts" and "a manual date change pauses".
5. **Reduced motion.** With `prefers-reduced-motion`, steps are one week and heights do not transition. Test: Task 2 "reduced motion steps a week"; Task 1 "transitions off when reduced".

Create `app/client/src/map/columns.ts`:

```ts
/**
 * 3D column sizing. Heights are meters at REF_ZOOM and are rescaled by zoom (elevationScale), so a
 * column keeps about the same screen height whether the camera fits the whole region or one port.
 */
export const REF_ZOOM = 4;

/** Elevation in meters per vessel a day at REF_ZOOM: Hormuz before the war (about 68) is the tallest column. */
export const METERS_PER_VESSEL = 25000;

/** A closed strait still reads as a place: a short stub, never nothing. */
export const MIN_ELEVATION_VESSELS = 1.5;

/** Column radius in screen pixels. */
export const COLUMN_RADIUS_PX = { chokepoint: 9, port: 5 } as const;

/** Length of one height or color transition in ms, about one playback frame. */
const TRANSITION_MS = 120;

const ok = (v: number | null | undefined): v is number => v != null && Number.isFinite(v) && v > 0;

export function elevationOf(v: number | null | undefined): number {
  return Math.max(ok(v) ? v : 0, MIN_ELEVATION_VESSELS) * METERS_PER_VESSEL;
}

export const elevationScaleFor = (zoom: number): number => 2 ** (REF_ZOOM - zoom);

/** Altitude of the column top in meters at this zoom, for a label that sits on the column. */
export const labelZ = (v: number | null | undefined, zoom: number): number => elevationOf(v) * elevationScaleFor(zoom);

export function columnTransitions(reduced: boolean): { getElevation: number; getFillColor: number } | undefined {
  return reduced ? undefined : { getElevation: TRANSITION_MS, getFillColor: TRANSITION_MS };
}
```

Create `app/client/src/map/playback.ts`:

```ts
import { DAY, toT } from '../explore/dates';

/** About one month of data every 2 seconds: 30 days in about 2000 ms. */
export const YEAR_TICK_MS = 66;
/** Under prefers-reduced-motion: a week per step, about the same pace through the year. */
export const REDUCED_STEP_DAYS = 7;
export const REDUCED_TICK_MS = 466;

const iso = (t: number) => new Date(t).toISOString().slice(0, 10);

export function dayStepsBetween(start: string, end: string, stepDays: number): string[] {
  const t0 = toT(start);
  const t1 = toT(end);
  if (!(t1 > t0)) return [start.slice(0, 10)];
  const out: string[] = [];
  for (let t = t0; t < t1; t += stepDays * DAY) out.push(iso(t));
  out.push(iso(t1));
  return out;
}

export const nextIndex = (steps: string[], current: string): number => {
  const i = steps.findIndex((s) => s > current);
  return i;
};

export const startIndex = (steps: string[], current: string): number => {
  const i = nextIndex(steps, current);
  return i < 0 ? 0 : i;
};

/** Frame interval for an answer series: 1 s a frame, clamped so the whole series takes 5 to 12 s. */
export function answerTickMs(frames: number): number {
  if (frames <= 0) return 1000;
  const total = Math.min(12000, Math.max(5000, frames * 1000));
  return Math.round(total / frames);
}
```

Create `app/client/src/map/usePlayback.ts`:

```ts
import { useCallback, useEffect, useRef, useState } from 'react';
import { nextIndex, startIndex } from './playback';

interface Opts {
  steps: string[];
  tickMs: number;
  date: string;
  setDate: (d: string) => void;
}

/**
 * Plays the selected date through `steps`, one step per tick, stopping on the last step. A date
 * change that playback did not make itself (a slider drag, a tour step) pauses it.
 */
export function usePlayback({ steps, tickMs, date, setDate }: Opts) {
  const [playing, setPlaying] = useState(false);
  const lastSet = useRef<string | null>(null);

  const play = useCallback(() => {
    if (steps.length === 0) return;
    const d = steps[startIndex(steps, date)];
    lastSet.current = d;
    setDate(d);
    setPlaying(true);
  }, [steps, date, setDate]);
  const pause = useCallback(() => setPlaying(false), []);
  const toggle = useCallback(() => (playing ? pause() : play()), [playing, play, pause]);

  // Someone else moved the date: stop.
  if (playing && lastSet.current !== null && date !== lastSet.current) {
    lastSet.current = null;
    setPlaying(false);
  }

  useEffect(() => {
    if (!playing) return;
    const id = window.setTimeout(() => {
      const i = nextIndex(steps, date);
      if (i < 0) {
        setPlaying(false);
        return;
      }
      lastSet.current = steps[i];
      setDate(steps[i]);
    }, tickMs);
    return () => window.clearTimeout(id);
  }, [playing, date, steps, tickMs, setDate]);

  return { playing, play, pause, toggle };
}
```

```tsx
function useReducedMotion(): boolean {
  const [reduced, setReduced] = useState(() => window.matchMedia('(prefers-reduced-motion: reduce)').matches);
  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    const on = () => setReduced(mq.matches);
    mq.addEventListener('change', on);
    return () => mq.removeEventListener('change', on);
  }, []);
  return reduced;
}
```

```ts
import { ROW_INDEX, dateColumn, toNum, type GenieLayerSpec } from './genieLayer';

type Row = Record<string, unknown>;

export interface SeriesFrame {
  value: number | null;
  pct: number | null;
  rowIndex: number;
}

export interface SeriesPlace {
  key: string;
  name: string;
  position: [number, number];
  frames: Map<string, SeriesFrame>;
}

/** A Genie answer about places over time: one frame per place per date, in date order. */
export interface TimeSeries {
  dates: string[];
  /** Every date is the first of a month (a monthly series). */
  monthly: boolean;
  valueField: string;
  pctField: string | null;
  /** The value is a daily rate (a 7-day average or a daily count), so labels say "a day". */
  perDay: boolean;
  places: SeriesPlace[];
}

const PCT = /pct|percent/i;
const PER_DAY = /7d_avg|per_day|daily|^n_total$/i;

/** YYYY-MM-DD from a month ("2026-02"), a day or a timestamp; null for anything else. */
export function normDate(v: unknown): string | null {
  if (typeof v !== 'string') return null;
  const s = v.trim();
  if (/^\d{4}-\d{2}$/.test(s)) return `${s}-01`;
  const m = /^(\d{4}-\d{2}-\d{2})/.exec(s);
  return m ? m[1] : null;
}

/** The count to draw as height: 7-day averages first, then n_total, then calls or transits, then any non-percent number. */
export function seriesValueField(columns: string[], rows: Row[], skip: string[]): string | null {
  const numeric = columns.filter(
    (c) => !skip.includes(c) && !c.startsWith('__') && rows.some((r) => toNum(r[c]) !== null)
  );
  const nonPct = numeric.filter((c) => !PCT.test(c));
  const pick = (re: RegExp) => nonPct.find((c) => re.test(c));
  return pick(/7d_avg/i) ?? pick(/^n_total$/i) ?? pick(/calls|transits/i) ?? nonPct[0] ?? null;
}

const inRange = (lat: number, lon: number) => Math.abs(lat) <= 90 && Math.abs(lon) <= 180;

export function timeSeriesOf(spec: GenieLayerSpec): TimeSeries | null {
  if (spec.kind !== 'points') return null;
  const rows = spec.rows;
  const columns = rows[0] ? Object.keys(rows[0]) : [];
  const dateField = dateColumn(columns, rows);
  if (!dateField) return null;
  const skip = [spec.latField, spec.lonField, dateField, ...(spec.nameField ? [spec.nameField] : [])];
  const valueField = seriesValueField(columns, rows, skip);
  if (!valueField) return null;
  const pctField = columns.find((c) => PCT.test(c) && !c.startsWith('__') && rows.some((r) => toNum(r[c]) !== null)) ?? null;

  const places = new Map<string, SeriesPlace>();
  const dates = new Set<string>();
  rows.forEach((r, i) => {
    const d = normDate(r[dateField]);
    const lat = toNum(r[spec.latField]);
    const lon = toNum(r[spec.lonField]);
    if (!d || lat === null || lon === null || !inRange(lat, lon)) return;
    const key = `${lon.toFixed(4)},${lat.toFixed(4)}`;
    const name = spec.nameField && r[spec.nameField] != null && r[spec.nameField] !== '' ? String(r[spec.nameField] as string) : `Place ${places.size + 1}`;
    const place = places.get(key) ?? { key, name, position: [lon, lat] as [number, number], frames: new Map() };
    const idx = typeof r[ROW_INDEX] === 'number' ? (r[ROW_INDEX] as number) : i;
    place.frames.set(d, { value: toNum(r[valueField]), pct: pctField ? toNum(r[pctField]) : null, rowIndex: idx });
    places.set(key, place);
    dates.add(d);
  });
  const sorted = [...dates].sort();
  const list = [...places.values()].filter((p) => [...p.frames.values()].some((f) => f.value !== null));
  if (sorted.length < 2 || list.length === 0) return null;
  return {
    dates: sorted,
    monthly: sorted.every((d) => d.endsWith('-01')),
    valueField,
    pctField,
    perDay: PER_DAY.test(valueField),
    places: list,
  };
}

export function frameOn(series: TimeSeries, date: string) {
  let pick: string | null = null;
  for (const d of series.dates) if (d <= date) pick = d;
  const at = pick ?? series.dates[0] ?? null;
  return {
    date: at,
    values: series.places.map((place) => ({ place, frame: at ? (place.frames.get(at) ?? null) : null })),
  };
}

export function fmtFrameDate(series: TimeSeries, date: string): string {
  const t = Date.parse(`${date}T00:00:00Z`);
  if (Number.isNaN(t)) return date;
  return new Date(t).toLocaleDateString(
    'en-US',
    series.monthly ? { month: 'short', year: 'numeric', timeZone: 'UTC' } : { month: 'short', day: 'numeric', year: 'numeric', timeZone: 'UTC' }
  );
}
```
